A controlled search

Qwen proposes bounded colour matrices, palettes, line and material controls. A trusted renderer applies them to cached rich paths from existing model-authored interpretations; it does not redraw each building or run generated code on the host. Fixed paths do not guarantee legibility: colour and edge choices can still hide architectural details.

The geometry is not verified architectural ground truth. Parameter samples are exploratory, not a learned style or reward. Failed/blank variants are retained in provenance but are not offered as paintings to vote on.

Each card is one operator with several parameter variations. Viewed means decoded and at least half-visible in the gallery viewport, or explicitly opened in the inspector—not eye tracking. Exposure is cumulative across earlier saved judgments when editing this source. Unviewed options are not labelled as rejected. None is an aesthetic abstention from keeping, while Pass skips this source.

Choices save automatically to the same private single-owner server. No automatic model forwarding or training. Old paired judgments keep their original format and history.
